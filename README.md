## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Service Unifier** | Run all your web apps and messengers in one tabbed desktop window |
| **Custom Workspaces** | Create named workspaces grouping related services for focus |
| **Notification Control** | Mute, badge or prioritize notifications per individual service |
| **Private Services** | Add any web app as a custom private service with cookie isolation |
